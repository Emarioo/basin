
If you are feeling lost in the purpose of this Compiler project read this:

If the compiler, language and ecosystem is great then that's a bonus not the primary goal.

This is a compiler i can develop specifically for my operating system. The possibilities are essentially endless, my mind has unfortunately become narrower with time.
The compiler is made on Linux and Windows since i have a debugger there so the compiler can become small and very portable with few dependencies. But still a complete and useful system language.

Small codebase, < 100K lines

You can experiment with features and good API design and new compiler/language versions that don't break existing programs.

This is an opportunity to experiment with test test systems.
